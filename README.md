# 算算星球

儿童三科（数学 / 语文 / 英语）学习练习 App，基于 uni-app（Vue3 + Vite），纯本地存储、无需账号，自用版本。

## 功能

- **数学（1-6 年级）**：加减乘除、四则混合、凑十/破十法、进位退位、连加连减、括号混合、有余数除法、比大小、填空、判断、单位换算、小数加减、分数加减，按年级课标综合出题
- **语文（1-6 年级）**：反义词、选读音、量词、古诗填空、近义词、成语填空
- **英语（3 年级起）**：字母练习、看图识词、单词翻译、缺字母、选词填空
- **趣味游戏**：限时挑战（60 秒连击）、气球抢答、数字对对碰、天平砝码、翻牌记忆
- **学习管理**：错题本（自动收录、重练）、每日打卡、练习统计、家长设置（音效、护眼、自动跳题、每日目标）

## 运行

```bash
npm install
npm run dev:h5     # H5 预览
npm run build:h5   # H5 构建
npm run build:mp-weixin  # 微信小程序构建
```

技术栈：uni-app 3 / Vue 3 / Vite 5，题目全部由本地引擎生成，无任何网络请求。
